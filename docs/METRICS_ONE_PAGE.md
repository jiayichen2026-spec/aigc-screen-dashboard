# AIGC互动大屏 · 指标说明

目标用户：品牌活动运营人员。通过参与、生成、领取、审核和设备数据，定位需要进一步排查的点位与时段。所有数据均为模拟数据。

| 指标 | 定义与计算口径 | 运营行动 |
| --- | --- | --- |
| 参与人数 | 所选日期与点位内，开始有效体验的匿名用户ID（visitor_id）去重数。包含开始体验后未提交生成的会话；跨日、跨点位汇总重新去重。 | 对比点位与时段的参与规模，调整现场引导与活动安排；结合体验次数判断重复参与。 |
| 生成成功率 | 成功任务数 ÷（成功任务数＋失败任务数）。排队、处理中不进入分母；同一逻辑任务的内部重试不新增任务数。 | 查看失败代码、超时与重试记录，定位服务或排队问题；排队、处理中单独关注。 |
| 扫码转化率 | 发生扫码的体验会话数 ÷ 已展示可领取结果的体验会话数。每会话最多计一次转化；审核拦截或待审核结果不进入分母。 | 检查结果展示与扫码引导、二维码可见性，结合现场反馈排查领取流失；不推断购买转化。 |
| 平均生成时长 | 成功任务从提交到完成的总耗时 ÷ 成功任务数，单位为秒，含排队与内部重试。失败和未结束任务不进入均值。 | 拆看排队、执行与重试耗时，并结合成功率判断稳定性；不将总耗时直接归因于模型。 |
| 内容审核 | 分别计数通过、拦截、待审核。审核通过率＝通过数 ÷（通过数＋拦截数）；待审核不进分母。生成成功与审核通过独立统计。 | 拦截增多时复核风险分类和规则；积压时检查队列并安排复核；不以放松审核换取通过率。 |
| 设备在线状态 | 固定快照时刻，距最近心跳≤300秒为在线，>300秒为离线，无心跳为未知。仅随点位筛选，不随业务日期改变。 | 离线时检查网络、供电和进程；未知时检查登记与采集。心跳年龄不等于确认故障时长。 |

时间归属：业务按北京时间的体验开始日筛选；生成、审核与扫码均观察到固定快照。数据覆盖2026-09-05至2026-10-04，快照为10月4日18:00；最后一天不是完整自然日。

边界处理：分母为0或没有日期覆盖时显示“—”；已覆盖但无体验时人数为0。人数不可直接加总，比例与均值按明细重算，显示时才舍入；小样本需谨慎解读。

异常使用：业务规则按预设案例窗口与所选日期交集复算，先检查样本门槛；设备看独立快照。阈值仅用于模拟演示，可能原因不等于确认根因。
