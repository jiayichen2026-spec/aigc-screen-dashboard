# AIGC互动大屏 · 指标说明

目标用户：品牌活动运营人员。通过参与、生成、领取、审核和设备数据，定位需要进一步排查的点位与时段。所有数据均为模拟数据。

| 指标 | 定义与计算口径 | 运营行动 |
| --- | --- | --- |
| 参与人数 | 筛选范围内开始体验的 visitor_id 去重数，含未提交生成的体验；跨日、跨点位汇总重新去重。 | 对比点位与时段规模，调整现场引导；结合体验次数看重复参与。 |
| 生成成功率 | 成功任务 ÷（成功＋失败任务）。排队、处理中不进分母；同一逻辑任务内部重试不新增任务数。 | 检查失败代码、超时与重试记录；单独关注排队及处理中任务。 |
| 扫码转化率 | 发生扫码的体验数 ÷ 已展示可领取结果的体验数。每体验最多计一次；拦截和待审核不进分母。 | 检查结果展示、二维码与扫码引导；不能据此推断购买转化。 |
| 平均生成时长 | 成功任务从提交到完成的总耗时 ÷ 成功任务数（秒），含排队和内部重试；排除失败及未结束任务。 | 结合成功率分析，拆看排队、执行与重试耗时，不直接归因于模型。 |
| 内容审核 | 分别计数通过、拦截、待审核。通过率＝通过 ÷（通过＋拦截），不含待审核；生成成功不等于审核通过。 | 拦截增多时复核风险类别与规则；待审核积压时检查队列并安排复核。 |
| 设备在线状态 | 固定快照距最近心跳≤300秒为在线，>300秒为离线，无心跳为未知。仅随点位筛选。 | 检查网络、供电、进程或心跳采集；心跳年龄不等于故障持续时长。 |

时间：业务按北京时间的体验开始日和点位筛选；生成、审核、扫码统一观察至2026-10-04 18:00快照。覆盖2026-09-05至10-04，最后一天未结束；设备不提供历史在线率。

完整漏斗：开始体验→提交生成→生成成功→审核通过→结果展示→扫码领取。每阶段按体验ID去重、属于前序同一批体验；相邻转化率＝本阶段÷上一阶段，差额＝上一阶段−本阶段。排队、处理中、待审核单列，差额不等于失败或流失；按差额状态排查对应环节，未知原因不臆测。

漏斗与卡片的分母不同：漏斗生成成功率包含排队、处理中，漏斗审核通过率包含待审核；扫码只代表扫码事件，不代表下载或购买。

边界与异常：分母为0或日期未覆盖显示“—”；已覆盖但无体验时人数为0。比例、均值按明细重算，显示时才舍入。异常按案例窗口与筛选日期交集复算并检查样本门槛；模拟阈值不是行业标准，建议不是确认根因。
