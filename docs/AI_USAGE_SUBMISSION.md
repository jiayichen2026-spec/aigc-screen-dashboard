# AI工具使用说明

## 使用的工具

主要AI工具为Codex，用于需求拆解、React／TypeScript／Vite页面实现、模拟数据、指标计算、异常与漏斗、调试及文档。ECharts绘图，GitHub管理源码，Vercel自动部署；Node测试与浏览器工具验证，Python／ReportLab排版PDF。

## 关键提示词

**任务目标（原始要求节选）**

“至少展示参与人数、生成成功率、扫码或分享转化、平均生成时长、内容审核和设备在线状态，并支持日期或点位筛选及异常查看。”

**数据与真实性（原始要求节选）**

“制作可复现的模拟数据及异常案例。” “所有数值从现有数据动态计算，不写死示例数字，不将可能原因表述为已确认原因。”

**漏斗口径（原始要求节选）**

“统一按体验 ID 计数，同一体验在每个阶段最多计一次，不能混入去重用户数或重试任务数。”

**阅读与导航（原始要求节选）**

“正文和重要说明尽量不低于 14px。” “不要机械地增加菜单数量。” “如使用页内定位，确保点击定位准确、滚动高亮合理，现有筛选状态保持不变。”
