# AI工具使用说明

## 使用的工具

主要AI工具为Codex，用于需求拆解、前端实现、模拟数据生成、指标计算、异常追查、测试和文档整理。工程使用React、TypeScript、Vite与ECharts；GitHub管理源码，Vercel部署可访问网页；Node测试与浏览器工具用于验证。

**任务目标（原始要求节选）**

“请使用模拟数据设计一个后台看板，至少展示参与人数、生成成功率、扫码或分享转化、平均生成时长、内容审核和设备在线状态，并支持日期或点位筛选及异常查看。”

**模拟数据（原始要求节选）**

“制作可复现的模拟数据及异常案例。”

**指标计算（原始要求节选）**

“编写指标计算逻辑，为页面接入数据做准备。”

**架构约束（原始要求节选）**

“如果有和之前搭建的架构冲突的部分，请不要修改源代码，先把错误报给我，我来进行决断。”
